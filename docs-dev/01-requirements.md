# 家味 · Family Chef — 需求文档

> 版本：v1.0 | 日期：2026-05-08 | 状态：已确认

---

## 一、项目概述

**家味（Family Chef）** 是一款面向家庭场景的点菜系统，旨在解决家庭成员之间的菜品选择、口味偏好管理和厨师（负责做饭的家庭成员）协作问题。

系统包含 **管理端** 和 **用户端** 两个入口：
- **用户端**：用于点菜、个人口味偏好管理、订单查看（登录用户身份为厨师时显示此选项）
- **管理端**：用于用户管理、菜品管理、食材管理、厨师管理、分类管理等后台管理功能

---

## 二、整体需求说明

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | 可以点菜、管理个人口味偏好、查看自己的订单 |
| 家庭厨师 | 除普通用户功能外，可查看所有待制作订单并进行处理 |
| 超级管理员 | 拥有所有权限，包括用户管理、菜品管理、系统配置等 |

> 注：同一用户可以同时拥有多个角色，通过角色切换功能切换视图。

### 2.2 核心业务流程

```
用户浏览菜品 → 添加菜品到订单 → 确认下单 → 厨师收到通知 → 厨师制作 → 标记完成 → 用户收到通知
```

## 三、功能需求清单

### 3.1 用户端功能（9 个功能点）

#### F-01 用户信息展示
- 登录后首页展示用户头像、用户名、角色信息
- 显示快捷统计：本周已点菜品数、收藏数、忌口食材数
- 提供"开始点菜"和"个人中心"两个主要入口

#### F-02 开始点菜入口
- 首页醒目位置展示"开始点菜"按钮
- 点击进入点菜页面

#### F-03 个人中心入口
- 首页提供"个人中心"入口
- 点击进入个人信息管理页面

#### F-04 个人信息编辑
- 修改用户名、密码等基础信息
- 修改邮箱等联系方式
- 角色切换功能（普通用户 / 家庭厨师 / 超级管理员）

#### F-05 个人口味编辑
- **不爱吃的食材**：用户可以添加自己不爱吃的食材，这些食材在菜品中会出现时显示黄色提示标签
- **严格忌口食材**：用户可以添加严格忌口的食材，这些食材在菜品中会出现时显示红色警告标签
- 支持食材的添加和删除操作

#### F-06 菜品浏览（核心功能）
- **瀑布式展示**：可选菜品通过选项卡瀑布式展示，动态加载，一次加载 20 条
- **多维度筛选**：
  - 按地区筛选：中餐、西餐、日料、印度菜、东南亚菜、黑暗料理界、其他
  - 按口味筛选：辣、甜、酸、清淡等
  - 按季节筛选：春季、夏季、秋季、冬季
  - 按我的收藏筛选
- **二级菜系筛选**：
  - 当选择"中餐"时，额外显示菜系二级筛选框，可选八大菜系（川菜、鲁菜、粤菜、苏菜、浙菜、闽菜、湘菜、徽菜）
  - 当选择"西餐"时，额外显示国家二级筛选框，默认选项为法国、美国、意大利
  - 二级选项默认值为"全部"
- **排序规则**：默认按菜名首字母排序，且按"无标签 > 不爱吃 > 严格忌口"的顺序排列
- **模糊查询**：支持菜名、食材模糊查询
- **忌口提示**：每个菜品选项卡右上角根据菜品是否包含当前用户不爱吃或严格忌口的食材添加不同标签：
  - 🟡 黄色标签：含有"不爱吃"的食材
  - 🔴 红色标签：含有"严格忌口"的食材

#### F-07 菜品详情
- 点击菜品选项卡可查看菜品详情
- 详情内容包括：菜品名称、图片、主要食材列表、菜品介绍、营养信息
- 显示安全提示：是否含有用户忌口食材
- 提供"收藏"和"加入订单"操作按钮

#### F-08 订单管理（用户端）
- **底部订单栏**：在屏幕下方提供已点菜品信息栏
  - 默认展示点菜数量
  - 展开后显示详细点单情况（菜品名称、数量等）
- **确认下单**：点击确认下单按钮，将订单提交给厨师
- **订单查看**：查看自己的历史订单及状态（待确认、制作中、已完成）

#### F-09 厨师订单查看（仅厨师角色）
- 当登录用户身份为厨师时，显示此选项
- 查看所有待制作订单
- 查看订单详情（点菜用户、菜品列表、下单时间）
- 标记订单完成

### 3.2 管理端功能（5 个功能点）

#### F-10 用户管理
- 用户列表查看
- 新增/编辑/删除用户
- 用户角色分配（普通用户 / 家庭厨师 / 超级管理员）
- 用户口味偏好查看和管理

#### F-11 菜品管理
- 菜品列表查看（支持搜索和筛选）
- 新增菜品：填写菜品名称、描述、图片、选择关联食材等
- 编辑菜品信息
- 删除菜品
- 菜品上下架管理
- 菜品与食材的关联管理

#### F-12 食材管理
- 食材主数据维护（名称、分类、描述等）
- 食材别名管理（同一食材的不同叫法映射）
- 食材的增删改查

#### F-13 厨师管理
- 厨师列表查看
- 厨师排班管理
- 厨师工作量统计

#### F-14 分类管理
- 地区分类管理（中餐、西餐等）
- 菜系分类管理（川菜、鲁菜等八大菜系）
- 口味分类管理（辣、甜、酸等）
- 季节分类管理（春季、夏季等）

### 3.3 其他功能

#### F-15 飞书集成
- 自动识别飞书账号，绑定系统用户
- 订单提交后自动推送通知到厨师的飞书账号
- 订单状态变更时推送通知给点菜用户

#### F-16 自动食材抽取
- 从非结构化文本（如菜品介绍）中自动抽取食材名称
- 与食材主数据进行匹配和映射

## 四、非功能需求

### 4.1 技术架构
- **部署方式**：单个 Docker 镜像部署
- **前端技术栈**：React + Vite
- **后端技术栈**：Python + FastAPI + UV
- **数据库**：SQLite（通过 Docker volume 持久化）

### 4.2 认证与安全
- 采用 JWT Token 进行身份认证
- 超级管理员默认账号：`admin` / `admin`（首次登录强制修改密码）
- 密码存储采用 bcrypt 加密

### 4.3 性能要求
- 菜品列表支持动态加载（瀑布流），每次加载 20 条
- 页面响应时间 < 1 秒
- 支持同时 10 个用户在线使用

### 4.4 响应式设计
- 适配 PC 端和移动端
- 移动端采用单列瀑布式布局
- PC 端采用多列网格布局

### 4.5 特色功能
- **个性化食材忌口提示**：根据用户口味偏好，智能提示菜品中的忌口食材（黄色/红色标签）
- **自动食材抽取**：从非结构化文本中自动识别和抽取食材
- **飞书集成**：自动推送订单通知到厨师飞书账号

| 食材管理 | 4 | 食材 CRUD、别名管理 |
| 分类管理 | 3 | 分类 CRUD、列表查询 |
| 收藏管理 | 2 | 添加/取消收藏、收藏列表 |
| 口味偏好 | 2 | 偏好设置、偏好查询 |
| 厨师管理 | 3 | 排班管理、工作量统计 |
| 系统管理 | 4 | 日志查询、系统配置 |
| 飞书集成 | 2 | 消息推送、账号绑定 |

> 详见《技术文档》中的完整接口定义。

## 七、页面原型

系统共包含 7 个核心页面原型（v2 响应式版本）：

1. **用户端首页** — 欢迎横幅、快捷统计、开始点菜入口、最近订单
2. **点菜页面** — 搜索、多维度筛选（地区/菜系/口味/季节）、菜品网格、忌口标签提示、底部订单栏
3. **个人中心** — 用户信息、口味偏好（不爱吃/忌口食材标签）、我的收藏、角色切换
4. **菜品详情** — 大图展示、食材标签、安全提示、菜品介绍、营养信息、加入订单
5. **厨师订单页** — 待制作/已完成统计、紧急订单高亮、订单详情与完成操作
6. **管理端首页** — 数据统计看板、6 个管理模块入口、最近动态、快捷操作
7. **菜品管理** — 搜索筛选、菜品列表（含状态标签）、编辑/删除操作、分页
