## Trust Boundaries
- The Sheet component is consumed here (no new auth surface).
- React Portal `createPortal(...)` to `document.body` is a new pattern in this codebase. It does not introduce a new XSS vector — the portal content is plain React children built from existing page state. No `dangerouslySetInnerHTML`. No URL or user-controlled string flows into the Portal'd element's className/style attribute.
- Click-outside relies on `document.mousedown` event bubbling. Portal'd content lives under document.body; mousedown still propagates from document to the React synthetic event system normally. The existing `e.target.closest('[data-dropdown-id]')` (AdminIngredientsPage) and `ingDropdownRef.current?.contains(e.target)` (AdminDishesPage) patterns work for portal'd content because `contains()` and `closest()` traverse the entire DOM regardless of parent React tree.
