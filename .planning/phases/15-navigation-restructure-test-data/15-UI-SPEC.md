# Phase 15 — UI Design Contract

> Visual and interaction contract for Phase 15 — Navigation Restructure & Test Data.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **No new visual language is introduced.** This phase restructures existing
> composites (Header / Sidebar / BottomBar / UserHomePage / OrderPage), inserts
> a Sheet wrapper around an existing chip-based filter block, and adds a
> development-only seed fixture. Every visual value reuses the established MD3
> design tokens in `frontend/src/css/tokens.css` and the existing composite CSS.
