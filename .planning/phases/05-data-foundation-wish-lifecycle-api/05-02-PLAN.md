**Method 6: `claim_wish(db: AsyncSession, wish_id: int, current_user: User) -> Optional[Wish]` — FLOW-02 + D-01 + DATA-08:**

Per D-01, this method MUST use a single atomic UPDATE statement. NEVER SELECT-then-UPDATE.

```python
@staticmethod
async def claim_wish(db: AsyncSession, wish_id: int, current_user: User) -> Optional[Wish]:
    """厨师认领愿望 (FLOW-02, D-01 原子并发安全).

    Router enforces role via require_role("chef", "admin").
    Returns:
      Wish instance on success.
      None if wish_id does not exist (router -> 404 per D-03).
    Raises:
      ValueError: if wish was just claimed or status changed (router -> 400 per D-02).
    """
    # 原子条件 UPDATE — single statement, no SELECT-then-UPDATE (D-01)
    result = await db.execute(
        update(Wish)
        .where(Wish.id == wish_id, Wish.status == "待处理")
        .values(status="准备中", claimed_by_chef_id=current_user.id)
    )
    if result.rowcount == 0:
        # Disambiguate: not-found (→ None → 404) vs already-claimed (→ ValueError → 400)
        existing = await db.execute(select(Wish.id).where(Wish.id == wish_id))
        if existing.scalar_one_or_none() is None:
            return None  # router: 404 (D-03)
        raise ValueError("该愿望已被认领或状态已变更")  # router: 400 (D-02)

    # Phase 6 hook: notify submitter that wish was claimed

    # Re-fetch with relationships loaded for response serialization
    result = await db.execute(
        select(Wish)
        .options(selectinload(Wish.submitter), selectinload(Wish.claimer))
        .where(Wish.id == wish_id)
    )
    return result.scalar_one_or_none()
```
