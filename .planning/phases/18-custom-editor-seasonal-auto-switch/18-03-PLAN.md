<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated user input → editor state | Names, hex strings, query parameters, and picker events are untrusted browser input. |
| editor state → `/api/themes` | Draft values cross into JWT-protected create/update requests. |
| editor preview → DOM style element | Generated CSS is applied to a local subtree while the user drags controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-07 | Tampering | `ThemeEditorPage` draft fields | mitigate | Restrict seeds to `#RRGGBB`, variants to the nine engine identifiers, and names to trimmed 1–100 characters before API calls. |
| T-18-08 | Cross-Site Scripting | custom theme name and preview | mitigate | Render names through React text nodes, never concatenate names into selector strings, and use the fixed `editor-preview` scope identifier for generated CSS. |
| T-18-09 | Repudiation | create/update save flow | mitigate | Wait for the API response, refresh the authenticated custom-theme list, show Chinese success/error toast, and navigate only after the requested mutation succeeds. |
| T-18-SC | Tampering | `npm install react-colorful` | mitigate | Install only after Plan 18-02 approval, pin `^5.8.0`, retain the generated lockfile, and run lint/build/token gates. |
</threat_model>
