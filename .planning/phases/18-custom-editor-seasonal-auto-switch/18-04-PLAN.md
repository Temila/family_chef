## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → seasonal context/bootstrap | Users or extensions can alter season toggle, hemisphere, cache, and active-theme JSON. |
| generated solar table → season resolver | Checked-in build data determines which preset is automatically selected. |
| dev-time Skyfield command → generated frontend source | A local generator produces the static constant consumed by the browser bundle. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-10 | Tampering | season localStorage keys | mitigate | Validate `fc_season_enabled` as the literal string `true`, hemisphere against `north|south`, and cached season against the four seasonal IDs; malformed values use safe defaults. |
| T-18-11 | Spoofing | automatic theme selection | mitigate | The resolver can select only four frontend preset IDs; it never accepts a custom ID or remote value as an automatic target. |
| T-18-12 | Denial of Service | FOUC bootstrap and season resolver | mitigate | Use the finite embedded 80-year table, catch JSON/storage/derivation failures, and fall back to the existing `fc_active_theme`/tokens.css path without network access. |
| T-18-13 | Tampering | generated solar-term data | mitigate | Generate deterministically from the approved Skyfield command, inspect exact 80×4 output, and commit the generated module together with the generator. |
| T-18-SC | Tampering | `uv run --with skyfield` generator resolution | mitigate | Plan 18-02 blocks package identity approval; Skyfield is never added to application runtime manifests or imported by frontend code. |
