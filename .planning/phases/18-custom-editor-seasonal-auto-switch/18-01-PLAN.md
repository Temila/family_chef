<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage/API theme payload → theme engine | Persisted source colors and variant strings are untrusted input before CSS generation. |
| theme engine → generated style element | Generated CSS is inserted into the document and is consumed by every component. |
| npm package manager → build | MCU code is supplied by the package graph and executes in the browser bundle. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01 | Tampering | `buildCssSync` input validation | mitigate | Reject non-`#RRGGBB` seeds and variants outside the nine-string whitelist before generating CSS. |
| T-18-02 | Denial of Service | MCU derivation and scoped preview callers | mitigate | Keep the synchronous path bounded to three validated seeds and one whitelisted variant; callers catch derivation failures and retain the existing theme. |
| T-18-03 | Elevation of Privilege | generated theme CSS | accept | Theme CSS changes presentation tokens only; no HTML, script, URL, or event-handler text is derived from user input. |
| T-18-SC | Tampering | npm install of `@material/material-color-utilities` | mitigate | Existing pinned `^0.4.0` package is reused; executor must run the repository token/build checks and not introduce a second color-utility package. |
</threat_model>
