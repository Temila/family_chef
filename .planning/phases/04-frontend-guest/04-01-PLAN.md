Parse response: read `res.text()`, if empty and not ok throw `Error('请求失败 (status)')`, if empty and ok return null, otherwise `JSON.parse(text)` and if not ok throw `Error(data.detail || '请求失败')`, else return data.     - `getQuantity(dishId)` — returns `cart.find(item => item.dish_id === dishId)?.quantity || 0`
    - `cartCount` — `cart.reduce((sum, item) => sum + item.quantity, 0)`
