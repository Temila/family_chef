# Milestone v1.1: 菜品愿望单 (Dish Wish List)

**Status:** ✅ SHIPPED 2026-07-24
**Phases:** 5-7
**Total Plans:** 11

## Overview

在 v1.0 家庭点菜系统的基础上，新增"菜品愿望单"功能：注册用户在菜单里找不到想吃的菜时，向厨师提交"愿望单"（菜名 + 可选参考链接 + 备注），厨师认领（独占）→ 推进（关联已上架菜品）→ 上架，或附原因拒绝，形成完整闭环。配套飞书通知（用户端应用内红点 + 厨师端飞书卡片推送）+ 移动端友好的三角色 UI（用户 / 厨师 / 管理员）。

## Milestone Summary

**Key Decisions:**

- UUID4 token for guest invite links (v1.0) → kept; no equivalent for wishes (user-bound, no link)
- 独立 `guest_invitations` 表 (v1.0) → 复用 `Wish` 模型 + 字段，无需新独立表
- Lazy expiry in DB layer (v1.0) → N/A for wishes (user-owned lifecycle)
- Atomic transaction for one-time use (v1.0) → atomic conditional UPDATE for concurrent claim (D-01, Phase 5)
- Decision: `naive_utc_now()` UTC-naive clock helper for all Phase 6 timestamp writes — prevents UTC+08 local vs SQLite UTC default mismatch
- Decision: `batch_alter_table(recreate=always)` for migration 3a41e4977098 — bypasses SQLite ADD COLUMN limitation
- Decision: `compute_has_unread` identity-masks non-submitters — submitter-only disclosure
- Decision: `WishNotificationService` separate module — keeps recipient resolution + failure isolation out of integration layer
- Decision: `fetchedOnce` + `setTimeout(100)` pattern — distinguishes "list really ready" from ".finally flips loading" race
- Decision: source-level NOTE marker (NOTE(07-04)) for missing startup hook — avoids unilateral architectural decision mid-phase

**Issues Resolved:**

- H-3 deep-link highlight race (07-05): requestSeq discard flipping loading before list actually rendered — closed with `fetchedOnce` flag + 100ms grace
- Migration gap 3a41e4977098 not applied to local DB (07-04): committed migration script + local DB out of sync — closed with `alembic upgrade head` + NOTE marker
- 2 critical review findings (CR-01 deep-link race, CR-02 modal submit reset) — closed
- 8 standard review findings (WR-01..08): duplicate cancellation guard, admin read-only mode, empty-result messaging, focus-refresh deduplication, wish tab count removal, modal focus a11y — all closed

**Issues Deferred (tech_debt):**

- `config.yaml` 缺 `app.url`，飞书深链回落占位 `https://family-chef.app` — 生产部署前需运维补齐
- 迁移 `f94f55868e87` 含 SQLite batch 缺陷，`alembic upgrade head from base` 仍依赖 `env.py` 加 `render_as_batch=True`
- 启动未自动跑 `alembic upgrade head`，架构决策延后（AUTO_MIGRATE env 候选）
- CORS `allow_origins: ['*']` 仍未收窄（v1.0 延后）
- Backend 测试套件漂移（107 失败）属既有，与 v1.1 无关
- IN-01: `WishDeepLinkRedirect` 未 encodeURIComponent(id)，低危可推迟
- IN-04: actingId 跨卡片点击残留，实际重现极低
- 前端全量 lint 基线仍红（≥90 错误属既有）

**Technical Debt Incurred:**

- `last_status_change_at` not written on `update_wish` content-edit (by design — preserves unread semantics) — needs explicit doc for future maintainers
- NOTE(07-04) flag in `main.py` documents the missing automatic alembic upgrade — needs follow-up architectural decision in next milestone
