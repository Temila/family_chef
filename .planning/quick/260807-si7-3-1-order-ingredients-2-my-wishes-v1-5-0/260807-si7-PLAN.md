# Quick Task 260807-si7 — 修复3个UI/功能问题

## Task 1: Order 页面高级筛选行排版修复

**Problem:** `OrderPage.jsx` 的筛选行使用内联样式（`display:flex; flexWrap:wrap`），没有 `justify-content: space-between`，导致排版与 ingredients 页面不一致。

**Reference:** `AdminIngredientsPage.jsx` 使用共享类 `.filter-action-row` + `.filter-action-row__filters` / `.filter-action-row__actions`。

**Fix:**
- **File:** `frontend/src/pages/OrderPage.jsx` (lines 353–381)
- Replace the inline-styled `<div>` with `className="filter-action-row"` container
- Move "高级筛选" button + "收藏" Chip into `<div className="filter-action-row__filters">`
- Move 排序 `<select>` + "共X道" `<span>` into `<div className="filter-action-row__actions">`

## Task 2: my-wishes FAB 按钮位置修复 + 版本号更新

**Problem:** `UserWishesPage.jsx` 的 FAB 按钮（`className="fab"`）未固定在右下角，而是出现在左上方遮挡侧边栏。

**Root Cause:** CSS 加载顺序问题。`FAB.css` 中 `.md-fab { position: relative }` 在 `styles.css` 的 `.fab { position: fixed }` 之后加载。两者 specificity 相同（0,1,0），后加载的 `position: relative` 覆盖了 `position: fixed`。

**Fix:**
- **File:** `frontend/src/css/styles.css` (line 168)
- Change selector from `.fab` to `.md-fab.fab`（specificity 0,2,0 > 0,1,0），确保 placement 规则始终胜出

**Version Update:**
- **File:** `config.yaml` (line 10)
- Change `version: "1.3.0"` to `version: "1.5.0"`

## Task 3: 管理员重置密码功能修复

**Problem:** 管理员编辑用户时输入密码无法生效。

**Root Cause:** 前端 `AdminUsersPage.handleSave` 将 `password` 放入 `PUT /users/{id}` 请求体，但后端 `UserUpdateRequest` schema 没有 `password` 字段，Pydantic 静默丢弃。

**Fix (后端):**
- **File:** `backend/app/routers/users.py`
  - `UserUpdateRequest` 添加 `password: Optional[str] = None` 字段 + field_validator（最小长度6）
  - `update_user` 路由将 `request.password` 传递给 service
- **File:** `backend/app/services/user_service.py`
  - `update_user` 方法添加 `password: Optional[str] = None` 参数
  - 当 password 非空时设置 `user.password_hash = hash_password(password)`
