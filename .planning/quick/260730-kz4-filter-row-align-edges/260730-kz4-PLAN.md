# Quick Task 260730-kz4: filter-action-row 边缘对齐

<objective>
用户要求「高级筛选」行左右缩进对齐：
- 高级筛选左侧边 ↔ 上方搜索栏左侧边
- 添加右侧边 ↔ 上方清空按钮右侧边
</objective>

<analysis>
### 精确测量（spacing 非线性：s1=4 s2=8 s3=12 s4=16 s5=24）
- `.search-bar { padding: 0 var(--md-spacing-4) }` → 搜索 input 左边缘 = **16px**
- search-bar 内按钮 div 有 `marginRight: var(--md-spacing-1)` → **清空右边缘 = W-20**（距右 20px）
- 当前 `.filter-action-row { padding: 0 var(--md-spacing-4) var(--md-spacing-2) }`：
  - 高级筛选左 = **16px** = input 左 ✓ **已对齐**
  - 添加右 = **W-16** = 距右 16px → 比清空多出 **4px**（突出去了）✗

### 结论
- **左侧已对齐**（高级筛选 16px = 搜索 input 16px），无需改动
- **右侧差 4px**（spacing-1）：添加需向左收 4px 才能与清空对齐
</analysis>

<fix>
给 `.filter-action-row__actions` 加 `margin-right: var(--md-spacing-1)`（4px），**完全镜像 search-bar 内按钮 div 的 marginRight 手法**：
- search-bar 按钮组 marginRight 4px → 清空在 W-20
- filter-action-row 按钮组 marginRight 4px → 添加在 W-20
- 两者右边缘精确对齐 ✓

为何用 margin-right 而非改 padding：
1. 镜像 search-bar 现有手法，语义一致（"右侧按钮组内缩 4px"）
2. 保持 `.filter-action-row` 左右 padding 对称（16px），不引入非对称 padding
3. 高级筛选（直接子元素）不受影响，左边缘仍在 16px = input 左
</fix>
