# Quick Task 260730-k5g: 菜品/食材管理页 action-bar 排版调整

<objective>
菜品管理（AdminDishesPage）和食材管理（AdminIngredientsPage）两页的 action-bar 排版统一调整：

1. **按钮重命名**：AdminIngredients 的「从菜谱解析」→「解析文本」（AdminDishes 已是「解析文本」，无需改）
2. **图标统一**：两页「解析文本」按钮都用 `edit`（铅笔）图标（AdminDishes 已是 edit；AdminIngredients 的 inventory-2 → edit）
3. **同行布局**：把「高级筛选」按钮移进 Header 的 `header-action-bar`，与「解析文本 + 添加」按钮位于**同一行**；「高级筛选」靠左对齐，「解析文本 + 添加」靠右对齐
4. 删除两页中独立的「高级筛选」外层 `<div style={{padding...}}>` 块（已合并进 action-bar）
</objective>

<investigation>
### 现状（两页结构一致）
- `Header actions={<div className="header-action-bar" style={{display:flex,gap}}>`parse+add`</div>}` → 由 Header composite 渲染在主行下方的 56px action bar
- 一个**独立**的 `<div style={{padding}}><Button>高级筛选</Button></div>` 块在 search-bar 之后（AdminDishesPage:553-561, AdminIngredientsPage:270-278）

### 当前 CSS（Header.css:150-156）
```css
.header-action-bar {
  display: flex;
  align-items: center;
  justify-content: flex-end;   /* 全部靠右 */
  gap: var(--md-spacing-2);
  height: 56px;
  padding: 0 var(--md-spacing-4);
}
```

### 关键约束（必须遵守）
**不能**把基类 `.header-action-bar` 的 `justify-content` 从 `flex-end` 改成 `space-between` —— 这会让所有**单按钮**页面（AdminUsers / AdminCategories / OrderDetail / DishDetail，Phase 15-04 引入）的按钮跑到左侧。必须用**修饰符类**只作用于这两页。

### Icon registry
- `edit`（EditIcon）存在（Icon.jsx:97）—— 两页统一使用
- `description`、`inventory-2` 也存在，但本次按用户决定用 `edit`
</investigation>

<locked_decisions>
- 图标：用户确认两页「解析文本」均用 `edit`（铅笔）图标
- 布局方式：用 `header-action-bar--split` 修饰符（不修改基类），仅 AdminDishes + AdminIngredients 使用
</locked_decisions>
