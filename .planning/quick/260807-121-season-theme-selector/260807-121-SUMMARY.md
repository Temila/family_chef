- Added `buildDefaultSeasonThemeMap()` pure function with frozen {spring,summer,autumn,winter} → preset-reference map (TDD: 4 unit tests RED→GREEN)

## Decisions Made
- **buildDefaultSeasonThemeMap returns frozen map with PRESETS references (not copies):** Plan specified "元素保持引用"; `Object.freeze` only protects outer shape, element identity preserved so single source of truth stays in PRESETS.
- **fouc-bootstrap kept PRESETS.find fallback instead of importing buildDefaultSeasonThemeMap:** Plan explicitly directed this — avoids dragging SEASONS→solar-terms.js into the first-frame IIFE bundle. Map[season] field-check guards against corrupt/missing map.
- **setSeasonTheme sets justEnabledRef.current=true:** Mirrors `setSeasonEnabled` immediate-effect pattern (theme-context.jsx:274-277) so changing the current season's theme forces the next `applyCurrentSeason` to re-apply even if cache would otherwise hit.
