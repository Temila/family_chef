# Quick Task 260730-ks4: 三个按钮移到搜索栏下方

<objective>
上一版 quick task（260730-k5g）把「高级筛选 / 解析文本 / 添加」三个按钮放进了 Header 的 `header-action-bar`，导致它们渲染在搜索栏**上方**。用户要求：这三个按钮必须在搜索栏**下方**，且「高级筛选」靠屏幕左侧、「解析文本 + 添加」靠屏幕右侧。

修正方案：从 `<Header>` 移除 `actions` 属性（Header composite 在 actions 为空时不渲染 56px action bar），改为在 search-bar 之后插入一个**页面级**的 `filter-action-row`，左/右分布。
</objective>

<current_state>
两页当前结构（错误位置）：
```jsx
<Header title="..." actions={
  <div className="header-action-bar header-action-bar--split">
    <Button>高级筛选</Button>
    <div style={{flex,gap}}><Button>解析文本</Button><Button>添加</Button></div>
  </div>
} />
<div className="search-bar">...</div>
{showAdvFilter && <Sheet>...</Sheet>}
```
问题：`actions` 由 Header composite 渲染在 Header 主行下方（搜索栏**之上**）。
</current_state>

<target_state>
```jsx
<Header title="..." />                       // 无 actions → 不渲染 action bar
<div className="search-bar">...</div>
<div className="filter-action-row">           // 搜索栏下方的新行
  <Button variant="tonal" size="sm" onClick={() => setShowAdvFilter(true)}>高级筛选</Button>
  <div className="filter-action-row__actions">
    <Button variant="tonal" size="sm" onClick={openParseModal/openExtractModal}><Icon name="edit" size={18} /> 解析文本</Button>
    <Button variant="filled" size="sm" onClick={openCreate}>+ 添加</Button>
  </div>
</div>
{showAdvFilter && <Sheet>...</Sheet>}
```
</target_state>

<locked_decisions>
- 布局位置：搜索栏**之后**、Sheet 块**之前**
- 对齐：`justify-content: space-between` → 高级筛选(左) / 解析文本+添加(右)
- 图标与文案保持 260730-k5g 的结果：「解析文本」+ `edit` 图标（两页一致）
- 用共享 CSS 类 `.filter-action-row`（两页复用，避免内联样式重复）
- 删除 260730-k5g 引入的 `.header-action-bar--split`（移动后零消费者，死代码）
</locked_decisions>
