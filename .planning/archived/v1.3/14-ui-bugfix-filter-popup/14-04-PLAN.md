    **BUG-02 修复（styles.css）：**

    问题：`.pc-data-table th::before` 在所有 `<th>` 内插入 48px 宽伪元素 + 8px margin-right，导致所有表头文字右移 56px，而 `<td>` 内容没有此偏移——表头与内容列错位。

    用户尝试 `thead tr::before` 后表头对齐了，但整表偏移到页面右侧。修复方案：移除通用的 `th::before`，改为仅对第一列表头应用 padding-left 偏移，使表头"名称"与表体内容（编辑按钮后的菜名）视觉对齐。

    操作步骤：

    ```css
    /* BUG-02: 第一列表头 padding-left 偏移，与含编辑按钮的表体内容对齐 */
    .pc-data-table th:first-child {
      padding-left: calc(var(--md-spacing-3) + 48px + var(--md-spacing-2));
    }
    ```

    **为什么这样改：** 管理页面表格第一列内容通常有编辑按钮（~48px）+ 间隙（8px），名称文字从约 68px 开始。第一列表头也要从同一位置开始才能视觉对齐。其他列不再应用 `::before`（原来 ALL th 都偏移导致了全表错位）。表体 `<td:first-child>` 保持不变——其内部已有编辑按钮产生自然偏移。

    **BUG-04 修复（AdminDishesPage.jsx）：**

    问题：点击外部关闭使用 `mousedown` 事件（lines 84-104），触发时立即 `setShowIngDropdown(false)`，React 可能在 `click` 事件冒泡到 `<div onClick={toggleIngredient}>` 之前就卸载了 Portal 菜单——导致食材选择 `onClick` 永远不执行。

    根因：Portal'd 菜单内容通过 `createPortal` 渲染到 `document.body`，不在 `ingDropdownRef.current.contains()` 范围内。mousedown 检测到点击在 ref 外 → 立即关闭 → Portal 卸载 → click 事件丢失。

    修复方案：将事件从 `mousedown` 改为 `click`，并在关闭前检查点击目标是否在 Portal'd 菜单内（通过 `data-ing-dropdown` / `data-sf-dropdown` 属性判断）。

    具体操作：

    1. 修改 line 84-93 的 `showIngDropdown` useEffect：

       ```javascript
       useEffect(() => {
         if (!showIngDropdown) return;
         const handler = (e) => {
           if (ingDropdownRef.current && !ingDropdownRef.current.contains(e.target)) {
             // BUG-04: 如果点击在 Portal'd 菜单内，不关闭（让 onClick 先执行）
             if (e.target.closest('[data-ing-dropdown]')) return;
             setShowIngDropdown(false);
           }
         };
         document.addEventListener('click', handler);  // 从 mousedown 改为 click
         return () => document.removeEventListener('click', handler);
       }, [showIngDropdown]);
       ```

    2. 修改 line 95-104 的 `showSfDropdown` useEffect：

       ```javascript
       useEffect(() => {
         if (!showSfDropdown) return;
         const handler = (e) => {
           if (sfDropdownRef.current && !sfDropdownRef.current.contains(e.target)) {
             if (e.target.closest('[data-sf-dropdown]')) return;
             setShowSfDropdown(false);
           }
         };
         document.addEventListener('click', handler);  // 从 mousedown 改为 click
         return () => document.removeEventListener('click', handler);
       }, [showSfDropdown]);
       ```

    3. 在 Portal'd 食材菜单的根 `<div>`（createPortal 调用处，现 line 1075）添加 `data-ing-dropdown` 属性：

       ```jsx
       <div data-ing-dropdown style={{...}}>
       ```

    4. 在 Portal'd 半成品菜单的根 `<div>`（现 line 1129）添加 `data-sf-dropdown` 属性：

       ```jsx
       <div data-sf-dropdown style={{...}}>
       ```

    **为什么这样改：** `click` 事件在元素 `onClick` React 合成事件之后冒泡到 document，确保 `toggleIngredient(ing.id)` 先执行。`closest('[data-ing-dropdown]')` 作为防御性检查——即使点击 Portal'd 菜单，也不会触发关闭。两步保证：事件顺序正确 + 菜单内容不引发意外关闭。
