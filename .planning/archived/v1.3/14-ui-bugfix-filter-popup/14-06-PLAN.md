<objective>
修复 REVIEW CR-01（关键 a11y 回归）+ 廉价缓解 WR-01/WR-06（Portal 下拉菜单不随滚动/缩放重定位）。

**CR-01 根因**：`AdminDishesPage.jsx` line 776-784（ingredient onClick）和 line 812-820（semifinished onClick）在 onClick 中用 `ingDropdownRef.current.getBoundingClientRect()` 捕获坐标并设置 `*DropdownCoords` state；但 line 785 / line 821 的 `onKeyDown` 仅 `setShowIngDropdown(!showIngDropdown)`，不捕获坐标。Portal 渲染条件 `{showIngDropdown && ingDropdownCoords && createPortal(...)}`（line 1087）需要 coords 非 null，而键盘激活从未设 coords → Portal 永不渲染。键盘用户根本无法打开下拉。违反 WCAG 2.1.1 + 4.1.2。

**WR-01/WR-06 缓解**：Portal dropdown 用 `position: fixed` + 一次性 `getBoundingClientRect()` 捕获，未注册 scroll/resize 监听。在 Modal 内滚动 Modal body 或旋转设备时，菜单视觉上脱离 trigger。最廉价的修复：open 时注册 scroll/resize/orientationchange 监听，事件触发时直接关闭下拉（接受"极端情况重新打开"的方式换取 0 复杂度）。

**Purpose:** 关闭 REVIEW CR-01（关键 a11y）+ 廉价缓解 WR-01/06（用户已接受关闭方案）。

**Output:** 键盘用户能打开下拉菜单；下拉菜单在 scroll/resize 时主动关闭而非视觉脱离。
</objective>

       ```jsx
       useEffect(() => {
         if (!showIngDropdown) return;
         const handler = (e) => {
           if (ingDropdownRef.current && !ingDropdownRef.current.contains(e.target)) {
             if (e.target.closest('[data-ing-dropdown]')) return;
             setShowIngDropdown(false);
           }

         const closeOnScroll = () => {
           setShowIngDropdown(false);
           setIngDropdownCoords(null);
         };
         document.addEventListener('click', handler);

           document.removeEventListener('click', handler);
           window.removeEventListener('scroll', closeOnScroll, true);
           window.removeEventListener('resize', closeOnScroll);
           window.removeEventListener('orientationchange', closeOnScroll);
         };
       ```
