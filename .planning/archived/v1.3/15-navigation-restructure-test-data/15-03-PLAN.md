<objective>
Wrap the existing Header `actions` payloads on the 3 multi-button management pages (AdminDishesPage, AdminIngredientsPage, ChefDishesPage) in `<div className="header-action-bar">` so the action buttons render BELOW the Header main row inside the new 56px action bar (per D-NAV01-01 and D-NAV01-03 from Phase 15-02). Each of these pages already had an inline `<div style={{ display: 'flex', gap: 'var(--md-spacing-2)' }}>` wrapper around its action buttons — the change adds `className="header-action-bar"` to that existing wrapper, preserving the inline styles so the visual is unchanged if Phase 15-02's CSS has not yet shipped.

Purpose: Without this wrap, the 3 pages' action buttons (解析文本 / 从菜谱解析 / 添加 / etc.) would render inside `.md-header__right` next to the avatar, conflicting with the new theme IconButton + avatar layout. Phase 15-02's Header.jsx only renders actions inside the main row if the caller passes them; this plan relocates the visual container for those 3 callsites.

Output: 3 modified page files. No new code paths, no new dependencies, no new CSS.
</objective>
